`npm run check`: lint, 54 теста (3 файла), TypeScript и production build прошли. BAT-тесты выполнялись через настоящий `cmd.exe` в Windows.

## Смена порта

Flow теперь использует только 5174. BAT-файлы вызывают Node.js-помощник, который выводит новый адрес и проверяет занятость нового порта. Порт 5173 остался у PawSpot. Во время проверки Flow не запускался и не останавливался на 5173. Проверочная вкладка закрыта, сервер Flow остановлен.

## Ограничения

- Новая проверка занятости порта 5174 другим приложением вручную не повторялась. Защита `strictPort`, распознавание владельца и тесты механизма сохранены.
- Физический Android-телефон не подключался. HTTP через LAN-IP с самого компьютера не доказывает доступ через Wi-Fi/Firewall с другого устройства.
- Firewall, тип сети и роутер не изменялись. Права администратора не запрашиваются BAT-файлами; изменение существующих правил Firewall может потребовать администратора вручную.
- Закрытие окна через X и отдельная установка Windows 10 не проверялись вручную. BAT проверены в текущем Windows-окружении; основной stop-путь использует Vite.close().
- Данные Kanban, формат хранения и Drag & Drop не менялись.
