25 октября 2026, Windows, Node.js 24.19.0.

## Результаты

`npm run check`: lint, 53 теста (3 файла), TypeScript и production build прошли. Из 53 тестов 17 добавлены для запускателя, включая два реальных запуска cmd.exe с BAT.

## Почему проверка выполнялась на 5179

Основной порт 5173 занят PawSpot. Пользователь явно попросил оставить его работающим. Для успешных сценариев использована временная копия проекта в игнорируемой папке с изменением константы порта **только в копии**. В отслеживаемых файлах сохранён фиксированный 5173 и strictPort. Тестовые серверы после проверки остановлены.

## Ограничения

- Успешный полный цикл на 5173 не выполнялся, пока этот порт занят PawSpot. Проверен отказ при конфликте; успешный цикл проверен на 5179.
- Физический Android-телефон не подключался. HTTP через LAN-IP с самого компьютера не доказывает доступ через Wi-Fi/Firewall с другого устройства.
- Firewall, тип сети и роутер не изменялись. Права администратора не запрашиваются BAT-файлами; изменение существующих правил Firewall может потребовать администратора вручную.
- Закрытие окна через X и отдельная установка Windows 10 не проверялись вручную. BAT проверены в текущем Windows-окружении; основной stop-путь использует Vite.close().
- Данные Kanban, формат хранения и Drag & Drop не менялись.
