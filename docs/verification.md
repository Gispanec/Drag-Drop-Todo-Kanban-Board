- `npm run test`: 36 тестов, 2 файла.
- `npm run build`: production-сборка создаётся.
- Аудит npm не обнаружил уязвимостей на момент установки.

## Ограничения проверки

- TouchSensor настроен с удержанием 180 мс и допуском 8 px. На ручке `touch-action: none`, на поверхности — `pan-y`. **Touch-жесты на физическом устройстве не проверялись.** Попытка проверки через эмуляцию Chrome остановлена инструментом Windows: он не смог уверенно определить URL окна. Проверка ширины 390 px сама по себе не является проверкой touch.
- Автоскролл включён в dnd-kit для горизонтальной доски и вертикальных колонок. Длинный список и реальный переход между off-screen колонками на телефоне вручную не проверены.
- После браузерной проверки дополнительно исправлено соответствие позиции отпускания позиции preview и упрощена защита от клика после drag. Финальные изменения прошли статические проверки, unit-тесты и сборку; повторная браузерная проверка ограничена остановкой инструмента.
- Safari и Firefox отдельно не проверялись.
- Добавление CI-конфигурации само по себе не означает завершение удалённого запуска GitHub Actions.

## Чек-лист физического устройства

1. `npm run dev -- --host 0.0.0.0`, открыть Network URL в телефоне той же сети.
2. Создать три карточки. Открыть обычным тапом и закрыть редактор.
3. Удерживать ручку 180 мс и перенести карточку выше/ниже.
4. Перенести в пустую колонку, затем между двумя карточками.
5. Перетянуть к краю экрана для горизонтального автоскролла.
6. Заполнить колонку, проверить прокрутку и автоскролл при переносе.
7. Проверить отмену и быстрое повторное перемещение. Обновить страницу и сверить порядок.
